# Minecraft (Web Edition)

A simple **browser-based Minecraft-like game** you can play right in your browser.

No download needed. Just open the page and start building / breaking blocks.

## Play Now

Once GitHub Pages is enabled, the game will be available at:

**https://aj-8a.github.io/minecraft/**

## How to Play

- **WASD** → Move
- **Mouse** → Look around
- **Left Click** → Break block
- **Right Click** → Place block
- **Space** → Jump
- **1-4** → Change block type

## Features

- Infinite flat world
- Place & break blocks
- First-person controls
- Multiple block types (Grass, Dirt, Stone, Wood)
- Runs fully in the browser (Three.js)

## How to Host (GitHub Pages)

1. Go to the repository **Settings**
2. Click **Pages** on the left
3. Under "Source", select **Deploy from a branch**
4. Choose branch `main` and folder `/ (root)`
5. Click Save

After 1-2 minutes your game will be live!

## Local Development

Just open `index.html` in any modern browser, or use a local server:

```bash
npx serve .
```

## Tech Stack

- HTML + CSS + JavaScript
- Three.js (3D rendering)
- Pointer Lock API (mouse look)
